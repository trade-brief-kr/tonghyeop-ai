# 통협꾹이의 AI로운 하루 v26 — AI 상무관 실시간 파견 + 배국장의 AI 빨간펜

v25 원본(`handover/pkg/index.html`, SHA-256 08235a5b…)은 그대로 두고, `tools/build_v26.py`로 만든 새 파일입니다.

## v25 대비 변경점 (홈·ODA·정상외교·국장 사진 배너는 손대지 않음)
- `<title>`의 v21 문구를 v26으로 바꿈. DOCTYPE 중복 등 다른 정리는 하지 않음.
- `<head>`에 프록시 주소 상수 한 줄 추가: `window.TGG_OFFICER_API=''` (상무관·빨간펜 공용 기본 URL)
- 빨간펜 상단 안내문(`.redpen-notice`) 한 줄: '규칙 기반 시연용 첨삭…생성형 AI…수행하지 않습니다'를 '규칙 기반 즉시 첨삭이 먼저 표시되고, AI 프록시가 연결되면 생성형 AI 문장 첨삭이 이어서 표시(선택 기능)'로 변경
- `</body>` 앞에 v26 CSS, 사전조사 내장본(`#v26MissionsInline`), v26 JS(`#v26OfficerModule`, `#v26RedpenModule`) 추가.
- 5개 중점국(몽골·우즈베키스탄·인도·사우디·인도네시아)에서 '파견하기'를 누르면 아래 순서로 진행:
  1. 글로벌 통상 브리프 공개 JSON 실시간 조회: `data/report.json`, 해당 국가 이슈가 3건 미만이면 최근 6일 archive까지
  2. `data/missions.json` 사전 심층조사 로드. 실패하면 HTML 내장본 사용.
  3. 현지 도착 → 정보 수집 → 분석 → 보고 4단계 연출
  4. 프록시를 거쳐 Gemini 무료 등급으로 종합 (국장보고 3줄, 진척 상태, 기회·위험, 다음 조치, 확인사항, 영문 요청서)
  5. 실패하면 규칙 종합, 사전조사도 없으면 v25 시나리오로 대체. 각 경우 배지 표시.
- 결과는 기존 '국장 보고용 1페이지 / 실무 검토용 상세보고 / 후속조치 관리카드' 탭, 1페이지 실무보고 미리보기, '영문 협조 요청서' 버튼에 표시. 출처는 [B#]=브리프, [M#]=사전조사로 링크.
- 하단 안내문(`.deep-disclaimer`)과 우측 상단 라벨은 v26 결과를 표시할 때만 모드에 맞게 바꿈. 국가·임무를 바꾸면 원문으로 복원.
- **배국장의 AI 빨간펜** (`src/v26-redpen.js`, `.css`):
  - '즉시 실행'을 누르면 v25 규칙 점검(사전 작성 모범안 또는 규칙 구조화)이 먼저 그대로 표시되고, 이어서 `/api/redpen`으로 Gemini 문장 첨삭을 요청합니다.
  - AI 결과: 국장 총평, 문장별 원문 → 수정 → 이유(3~6개, 분류 포함), 보고 전 확인사항. 원문에 없는 숫자나 원문과 맞지 않는 문장은 [확인 필요] 표시.
  - 배지: 🤖 AI 첨삭 / 🧩 규칙 점검 / 📁 v25 기본. AI 실패·시간초과(45초)·미설정·6,000자 초과 시에는 규칙 결과만 남기고 이유를 안내합니다.
  - 입력창 아래에 '공개·가상 문서만 넣으세요'(무료 등급 입력은 Google 서비스 개선에 활용될 수 있음) 안내와 글자 수(6,000자 한도) 표시.
  - 상무관→빨간펜 전달 후 '즉시 실행'을 누르면 전달된 보고서도 AI 첨삭됩니다. v25 빨간펜 코드·지침 라이브러리·10대 점검표는 그대로입니다.
- 비중점국과 기존 기능(ODA·정상외교·localStorage 키)은 v25 그대로.

## 로컬 실행
```bash
export GEMINI_API_KEY=...        # 값을 파일에 쓰지 말 것
node ../server/local.mjs          # http://localhost:8787 (정적 + /api/officer)
# AI 모드 테스트(상무관·빨간펜): http://localhost:8787/?officerApi=http://localhost:8787
# 회귀 점검처럼 연속 호출할 때: RATE_PER_MIN=30 node ../server/local.mjs
```
`?officerApi=`는 테스트용 덮어쓰기입니다. 실제 배포에서는 `index.html` 상단 상수(또는 `python3 tools/build_v26.py --api https://….workers.dev`)를 씁니다.
